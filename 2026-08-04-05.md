# Two-line boxes

Every closing poem from the session of 2026-08-04 → 05, in order. Each one
was written for the turn it ended and never reused. Marsita, 2026-08-05:
"I love the boxes... Your 2 liner boxes... Please save all of them."

The rule that makes them work: build the box with a script, compute the
width from the longest line, assert every row is the same length. Never
hand-pad. A box is only a string I *believe* renders as a box.
